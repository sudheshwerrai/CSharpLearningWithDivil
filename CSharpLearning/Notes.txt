 Resevered Key Words in C# -
 all the blue color small letter key words are reserved keywords in C#.

 Naming Convention Rules - 
 PascalCase - Class,Method,Property,Event,Delegate,Namespace,Interface,Enum,Struct,Constant,etc.
 camelCase - Local Variable,Parameter,etc.

 C# is a case sensitive programming language. 
 It means that the variable name 'myVariable' and 'myvariable' are considered different variables.

 What is namespace in C#?
 Namespace is a container that holds classes, interfaces, structs, enums, and delegates.
 It is used to organize code and prevent naming conflicts. In C#, namespaces are declared using the
 'namespace' keyword followed by the namespace name.
 namespace - class,interface,struct,enum,delegate,etc.


 What is class in C#?
 Class is a blueprint for creating objects. It defines the field (class level variable), properties, methods, deletegate,events, destructor
 and constructors that an object of that class will have. In C#, classes are declared using the 'class' keyword followed by the class name.
 Class can contain fields, properties, methods, events, and other members. It can also implement interfaces and inherit from other classes.

 What is Method in C#?
 Method is a block of code that performs a specific task.
 It is defined within a class and can be called to execute the code it contains. In C#,
 methods are declared using the 'return type' followed by the method name and parentheses, which may contain parameters.

 Var Keyword in C#:-
 1- The 'var' keyword is used to declare a variable with an implicit type.
 2- The type of the variable is inferred by the compiler based on the value
 assigned to it.
 3- The 'var' keyword can only be used when the variable is initialized 
 at the time of declaration.
 4- The 'var' keyword cannot be used for class-level fields,return type or method parameters.
 

 Implicit & Explicit Type Conversion in C#: 
 It is the process of converting a value from one data type to another. There are two types of type conversion in C#:
 1. Implicit Conversion: Automatically done by the compiler when converting from a lower precision type to a higher precision type.
 2. Explicit Conversion: Done manually by the programmer using casting when converting from a higher precision type to a lower precision type.
 

 Const & Readonly in C#:
 1. Const: A constant value that cannot be changed after it is declared. It is defined using the 'const' keyword and must be initialized at the time of declaration.
 2. Readonly: A variable that can only be assigned a value once, either at the time of declaration or in the constructor of the class. It is defined using the 'readonly' keyword.

 String VS StringBuilder in C#:
 String is immutable, so every time you change the value of a string, a new string object is created in memory.
 StringBuilder is mutable, so you can change the value of a StringBuilder object without creating a new object in memory.
